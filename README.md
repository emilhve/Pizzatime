# Pizzatime

Pizzatime is a small community restaurant-rating web app for central Padua, Italy. Visitors can browse and search the local restaurant list, open a place in Google Maps, and see its community rating. Signed-in users can give each restaurant a score from 1 to 5 pizza slices and manage their ratings from a personal profile.

Live app: [emilhve.github.io/Pizzatime](https://emilhve.github.io/Pizzatime/)

## Using the app

### Browse restaurants

The restaurant list is available without an account. Use the search field to filter places by name or address. Each row shows:

- The restaurant name and available address.
- The average score and number of submitted ratings.
- Your own score when signed in.
- A **Map** link that opens the location in Google Maps.

### Create an account and rate a place

1. Select **Sign in**, then switch to **Sign up**.
2. Enter a username, email address, and password. Usernames must contain 3-24 letters, numbers, or underscores, and passwords must contain at least 8 characters.
3. Confirm the account by email if email confirmation is enabled.
4. Select **Rate** beside a restaurant and choose a score from 1 to 5.

Selecting an existing score lets you change or remove it. Open your username in the top bar to see your profile, number of rated restaurants, personal average, and complete rating history.

### Administrator access

Accounts with the `admin` role have two additional sections on the profile page:

- **Add a place** adds a restaurant by name, address, and coordinates. Coordinates must be inside the configured central Padua area.
- **Users** lists registered accounts and allows an administrator to delete another account. Deleting an account also removes its ratings.

Admin status is stored in the database and cannot be granted through the browser interface.

## How it works

Pizzatime is a React single-page application written in TypeScript and built with Vite. The static frontend is hosted on GitHub Pages, while Supabase provides the hosted PostgreSQL database, authentication, Row Level Security, and the `admin-users` Edge Function.

The main data flow is:

1. The browser reads the public restaurant catalog from the Supabase `restaurants` table.
2. Public average scores come from the `get_restaurant_rating_averages` database function.
3. Supabase Auth manages email/password sessions.
4. Signed-in users read and write only their own rows in `userratings` and their own profile in `users`.
5. The `admin-users` Edge Function verifies the caller's session and admin role before using the service role to list or delete Auth accounts. The service-role key stays inside Supabase and is never sent to the browser.

The database rules are defined as versioned SQL migrations in [`supabase/migrations`](supabase/migrations). The frontend talks directly to Supabase through the publishable key; Row Level Security controls what each request may access.

## Data sources

The initial restaurant catalog is a snapshot of OpenStreetMap data exported on September 18, 2026. It includes restaurant names, addresses when available, OpenStreetMap object IDs, and coordinates within an approximately 2.5 km by 2.5 km area in central Padua. The imported snapshot is stored in [`20260918140000_import_restaurants.sql`](supabase/migrations/20260918140000_import_restaurants.sql).

Restaurant data is provided by [OpenStreetMap contributors](https://www.openstreetmap.org/copyright) under the [Open Database License](https://opendatacommons.org/licenses/odbl/). The catalog is a snapshot rather than a live OpenStreetMap feed, so later changes on OpenStreetMap are not synchronized automatically. Administrators can add additional places to the app; those entries do not have an OpenStreetMap ID.

Ratings, usernames, roles, and account information are generated by Pizzatime users and stored in Supabase. The overview image of Padua's location is credited in the app to [Maps of India](https://www.mapsofindia.com/world-map/italy/padua/location-map.html). Restaurant map links are generated from stored coordinates and open in Google Maps.

## Local development

Requirements:

- Node.js 24, matching the deployment workflow
- npm
- A Supabase project for a fully working app
- Supabase CLI for migrations and Edge Function deployment

Install the dependencies:

```sh
npm install
```

Create `.env.local` in the project root:

```dotenv
VITE_SUPABASE_URL=https://YOUR_PROJECT_REF.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=YOUR_PUBLISHABLE_KEY
```

Use the project URL and publishable key from the Supabase dashboard. Never place a secret or service-role key in a `VITE_` variable because Vite includes those values in browser code.

Start the development server:

```sh
npm run dev
```

Other useful commands:

```sh
npm run lint
npm run build
npm run preview
```

On Windows, use `npm.cmd` or `npx.cmd` if PowerShell blocks the corresponding script files.

## Supabase setup

Link the repository to a Supabase project and apply the migrations:

```sh
npx supabase login
npx supabase link --project-ref YOUR_PROJECT_REF
npx supabase db push
```

Deploy the admin account-management function separately from the frontend:

```sh
npx supabase functions deploy admin-users --project-ref YOUR_PROJECT_REF
```

To grant an existing account administrator access, update its matching row in `public.users` using the Supabase SQL editor. Replace the email address with the intended account:

```sql
update public.users
set role = 'admin'
where user_id = (
  select id from auth.users where email = 'admin@example.com'
);
```

## Deployment

Pushing to `main` runs [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml). The workflow installs dependencies, builds the Vite app, uploads `dist`, and deploys it to GitHub Pages. The repository must have these GitHub Actions secrets:

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_PUBLISHABLE_KEY`

The Vite base path is `/Pizzatime/` to match the GitHub Pages project URL. The Pages workflow deploys only the static frontend; database migrations and the `admin-users` Edge Function must be deployed with the Supabase CLI when they change.
